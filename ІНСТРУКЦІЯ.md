# ТУ САМОСТІЙНОЇ HR ДАШБОРДУ З АВТОМАТИЧНИМ ОНОВЛЕННЯМ

## ЧИ РОБЛЯТЬ

1. **Python скрипт** — читає твій Excel файл і генерує HTML дашборд
2. **GitHub Actions** — запускає скрипт кожен день о 9 ранку автоматично
3. **Netlify** — показує дашборд на публічному посиланні

## НАЛАШТУВАННЯ (30 хвилин один раз)

### Крок 1: GitHub

1. Заходи на https://github.com (зареєструйся, якщо ще немає)
2. Клікни **New** → створи новий репозиторій
3. Назви: `hr-dashboard`
4. Описання: `HR Dashboard`
5. Встанови **Public**
6. Створи репозиторій

### Крок 2: Завантажи файли у GitHub

1. Клікни **Upload files** у репозиторії
2. Завантажи:
   - `HR_System.xlsx` (твій Excel файл)
   - `generate_dashboard.py` (скрипт що я дав)

### Крок 3: GitHub Actions (автоматичне оновлення)

1. У репозиторії клікни **Actions** (вкладка)
2. Клікни **set up a workflow yourself**
3. Назви файл: `update-dashboard.yml`
4. Вставь цей код:

```yaml
name: Update Dashboard

on:
  schedule:
    - cron: '0 9 * * *'  # О 9 ранку кожен день

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.9'
      
      - name: Install dependencies
        run: pip install openpyxl
      
      - name: Generate dashboard
        run: python generate_dashboard.py
      
      - name: Commit and push
        run: |
          git config --global user.name "GitHub Actions"
          git config --global user.email "actions@github.com"
          git add index.html
          git commit -m "Update dashboard $(date)" || true
          git push
```

5. Клікни **Commit changes**

### Крок 4: Netlify (показує дашборд)

1. Заходи на https://netlify.com (зареєструйся через GitHub)
2. Клікни **New site from Git**
3. Вибери твій GitHub репозиторій `hr-dashboard`
4. В налаштуваннях:
   - Build command: `echo "No build needed"`
   - Publish directory: `.` (корневою папка)
5. Розгорни сайт

Netlify дасть тобі посилання типу: `https://hr-dashboard-xyz.netlify.app`

### Крок 5: Добавиш Excel файл у GitHub щоночі

Щоб скрипт працював правильно, потрібно щоб твій Excel був завжди свіжий.

**Варіант А (Найпростіше):**
- Зберігаєш Excel у **Google Drive** або **Dropbox**
- Кожен день експортуєш новий файл та завантажуєш у GitHub вручну

**Варіант B (Автоматично):**
- Використовуєш **GitHub Desktop** додаток
- Копіюєш файл → він автоматично завантажується

## ГОТОВО!

Тепер:
- О 9 ранку скрипт автоматично запускається
- Читає твій Excel
- Генерує новий дашборд
- Netlify оновлює посилання

Ти даєш посилання Netlify власникам.
Вони вводять пароль `настя 25` і бачать дашборд.

## ЩОДЕННИЙ ПРОЦЕС

Тебе треба робити одне:
1. Вносиш дані у свій Excel на комп'ютері
2. Експортуєш його як Excel (Файл → Завантажити)
3. Завантажуєш новий файл у GitHub (натискаєш Upload files)
4. Всё

О 9 ранку дашборд оновляється автоматично.
